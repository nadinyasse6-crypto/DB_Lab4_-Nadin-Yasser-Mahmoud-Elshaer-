## Project Overview
A web-based Library Management System built using Python (Flask), MySQL, and Bootstrap as part of the Database Systems Lab coursework. It features user authentication, full CRUD operations, advanced database queries, reports, book loans management, and relational constraints with cascading deletes (`ON DELETE CASCADE`).
